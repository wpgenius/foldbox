Documentation

Everything you need to add Foldbox to a page, configure it and make it your own. For a quick look, try the demos first.

Install

Foldbox is one CSS file and one JavaScript file with no dependencies. Load them from jsDelivr:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/wpgenius/foldbox@1/dist/foldbox.min.css">
<script src="https://cdn.jsdelivr.net/gh/wpgenius/foldbox@1/dist/foldbox.min.js"></script>

@1 follows the latest 1.x release; pin an exact version such as @ in production. Or download foldbox.min.js and foldbox.min.css from the latest release and host them yourself. The readable sources are in src/.

The script sets window.Foldbox. It is a UMD module, so CommonJS (require()) and AMD loaders work too.

Lightbox

Open from JavaScript

Pass a list of items and, optionally, options. origin is the element the gallery grows out of, usually the thumbnail that was clicked.

Foldbox.open(
	[
		{ src: 'photo-1.jpg', thumb: 'photo-1-thumb.jpg', alt: 'Beach', caption: '<h4>Beach</h4><p>Summer 2026</p>' },
		{ src: 'clip.mp4', poster: 'clip.jpg', thumb: 'clip-thumb.jpg' },
		{ src: 'https://www.youtube.com/watch?v=aqz-KE-bpKQ' },
		{ src: 'https://vimeo.com/76979871', thumb: 'vimeo-thumb.jpg' },
	],
	{ index: 0, origin: document.querySelector( '#cover' ) }
);

Bind links

Foldbox.bind() turns the links inside a container into a gallery. Each href is an item; the link's image becomes the thumbnail and the opening origin. Links added later work too, because one click listener is set on the container.

<div id="gallery">
	<a href="large-1.jpg" data-caption="First"><img src="small-1.jpg" alt=""></a>
	<a href="large-2.jpg" data-caption="Second"><img src="small-2.jpg" alt=""></a>
	<a href="https://youtu.be/aqz-KE-bpKQ">Video</a>
</div>
<script>
	const unbind = Foldbox.bind( '#gallery', { download: true } );
	// Later: unbind();
</script>

The first argument is a selector or an element. bind() returns a function that removes the listener; it reads options once, so call it again to change them.

Link attributeDescription
hrefThe item: image, video file, YouTube or Vimeo URL.
data-thumbThumbnail for the strip. Defaults to the link's image.
data-captionCaption, shown as plain text (see security).
data-typeimage, video, youtube or vimeo, when the URL doesn't show it.
data-posterPoster image for a video.
data-downloadDownload URL, or false to hide the button for this link.

Items

Videos

Video files play in the browser's own player. Give several formats with sources:

{
	type: 'video',
	sources: [
		{ src: 'clip.webm', type: 'video/webm' },
		{ src: 'clip.mp4', type: 'video/mp4' },
	],
	poster: 'clip.jpg',
}

YouTube (youtube.com/watch?v=, youtu.be/, /shorts/, /embed/) and Vimeo links show a poster with a play button. The player is loaded when the visitor presses it, and stops when they move to another slide or close the gallery. Add player parameters with youtubeParams and vimeoParams.

Methods

MethodDescription
Foldbox.open( items, options )Open a gallery. Returns the lightbox object.
Foldbox.bind( container, options )Open links inside the container in a gallery. Returns an unbind function.
Foldbox.grid( element, options )Make a filterable grid.
Foldbox.close()Close whichever gallery is open.
Foldbox.defaultsDefault options, shared by every gallery.
Foldbox.versionThe version string, e.g. ''.

The lightbox object returned by Foldbox.open():

MethodDescription
next(), prev()Go to the next or previous item.
goTo( index )Go to an item by its position (from 0).
play(), pause()Start or stop the slideshow.
toggleZoom()Zoom the current image in or out.
toggleFullscreen()Enter or leave fullscreen.

Only one gallery is open at a time; opening another closes the first.

Callbacks

onOpen, onChange and onClose receive the current index, the current item and the lightbox object.

Foldbox.open( items, {
	onChange( index, item, lightbox ) {
		history.replaceState( null, '', '#photo-' + ( index + 1 ) );
	},
	onClose() {
		history.replaceState( null, '', location.pathname );
	},
} );

Themes and styling

The gallery is dark by default. Choose a built-in theme with the theme option:

Foldbox.open( items, { theme: 'light' } );     // 'dark' (default), 'light' or 'auto'
Foldbox.bind( '#gallery', { theme: 'auto' } ); // follows the visitor's light/dark setting

CSS properties

Change colours and sizes with CSS custom properties on .foldbox:

.foldbox {
	--foldbox-bg: rgba(0, 0, 0, 0.9);
	--foldbox-accent: #ffcc00;
	--foldbox-thumb-size: 72px;
	--foldbox-top: 32px; /* leave room for a fixed header */
	--foldbox-z: 99999;
}
PropertyUsed for
--foldbox-bgBackdrop
--foldbox-colorText and icons
--foldbox-mutedCounter, captions, error text
--foldbox-accentFocus ring, slideshow progress, active thumbnail, spinner
--foldbox-btn-bg, --foldbox-btn-hoverToolbar and arrow buttons
--foldbox-thumb-bgThumbnail placeholder
--foldbox-spinner-trackLoading spinner track
--foldbox-thumb-sizeThumbnail size
--foldbox-topSpace above the gallery, e.g. for a fixed admin bar or header
--foldbox-zStacking order (z-index)

Your own theme

Put the properties on a class and pass it with className:

.foldbox.my-sepia {
	--foldbox-bg: rgba(40, 30, 20, 0.96);
	--foldbox-color: #f4e9d8;
	--foldbox-muted: rgba(244, 233, 216, 0.7);
	--foldbox-accent: #e0b872;
}
Foldbox.open( items, { className: 'my-sepia' } );

Translation

Every text in the gallery comes from labels. Pass only the ones you want to change; %1 and %2 in counter are the current position and the total.

Foldbox.open( items, {
	labels: {
		dialog: 'Galerie',
		close: 'Fermer',
		prev: 'Précédent',
		next: 'Suivant',
		zoomIn: 'Zoom avant',
		zoomOut: 'Zoom arrière',
		fullscreen: 'Plein écran',
		exitFullscreen: 'Quitter le plein écran',
		play: 'Lancer le diaporama',
		pause: 'Mettre en pause',
		download: 'Télécharger',
		playVideo: 'Lire la vidéo',
		counter: '%1 sur %2',
		error: 'Impossible de charger cet élément.',
	},
} );

The gallery works on right-to-left pages too.

Filterable grid

Foldbox.grid() animates a grid between filters: items that stay glide to their new place, hidden items fade and shrink, new ones grow in. It works with any layout: CSS grid, flex or floats.

const grid = Foldbox.grid( document.querySelector( '.grid' ), { itemSelector: ':scope > .card' } );

grid.filter( '.weddings' );                              // CSS selector
grid.filter( '*' );                                      // everything
grid.filter( ( item ) => item.dataset.year === '2026' ); // function
grid.filter( '.portraits', true );                       // no animation

Hidden items get the hidden attribute, so make sure your CSS hides them: .card[hidden] { display: none; }

OptionDefaultDescription
itemSelector':scope > *'Which elements are items.
duration400Animation time in ms.
easing'ease'CSS easing.

A typical setup with filter buttons:

const grid = Foldbox.grid( document.querySelector( '.grid' ) );
document.querySelectorAll( '[data-filter]' ).forEach( ( button ) => {
	button.addEventListener( 'click', () => grid.filter( button.dataset.filter ) );
} );

Captions and security

With Foldbox.open(), captions are inserted as HTML so you can add headings and links. Escape anything that comes from users, or set htmlCaptions: false to show captions as plain text.

Foldbox.bind() reads captions from page markup that other people (such as post authors) may control, so it shows them as plain text. Pass htmlCaptions: true only if you trust everyone who can edit that markup. Download links accept only http(s) and blob: URLs.

Privacy

  • YouTube and Vimeo players load only when the visitor presses play. Until then, no request goes to YouTube or Vimeo, except for thumbnails below.
  • YouTube uses youtube-nocookie.com (turn off with youtubeNoCookie: false).
  • YouTube items without your own thumb or poster load their thumbnail from i.ytimg.com when the gallery opens. Set youtubeThumbnails: false, or give your own images, to avoid that.

Accessibility

  • The gallery is a modal dialog (role="dialog", aria-modal) with a label.
  • Focus moves into the gallery, stays there while it is open, and returns to the element that opened it.
  • All controls are buttons with labels; slides that are not visible are hidden from screen readers.
  • Keyboard navigation works without a mouse.
  • Animations are turned off for visitors who ask for reduced motion.

Browser support

Current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile.

Contributing

Bug reports, ideas and pull requests are welcome on GitHub.

git clone https://github.com/wpgenius/foldbox.git
cd foldbox
npm install
npm run build
  • Open demo/index.html through a local web server to try your change.
  • In a pull request, change src/ (and docs) only. Don't commit dist/ or CHANGELOG.md, and don't change version numbers: the release workflow does that when the PR is merged.
  • Link the PR to its issue (Fixes #12); the changelog lists the issues closed in each release.
  • Releases are patch versions by default. Label the PR release: minor or release: major for a bigger bump.
